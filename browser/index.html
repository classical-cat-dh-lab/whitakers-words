Offline use and installation

Save the files here before disconnecting. On iPhone or iPad, open this site in Safari and use Share → Add to Home Screen. Open it from the Home Screen and save the dictionary there too. Other browsers may offer Install app. Installing an icon alone does not save the dictionary. Clearing this website’s data removes its offline files; reconnect and save them again.

Enter / Return to look up · Shift + Enter for a new line. Macrons are welcome.
