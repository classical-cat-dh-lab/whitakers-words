# Whitaker Words Modernization

A modern reimplementation of William Whitaker's WORDS, intended to provide a
reusable Latin dictionary and morphological analysis library.

This project is at its initial design stage. No rewritten engine or installable
release is available yet.

The planned library will return structured lexical and morphological candidates,
preserve ambiguous analyses and source provenance, and support offline use.

## Upstream

William Whitaker created the original WORDS program and dictionary. Source
references include the [maintained Ada project](https://github.com/mk270/whitakers-words)
and the [historical 1.97FC distribution](https://github.com/dsanson/Words).
This project is an independent reimplementation effort.
