# Offline help

## Save the dictionary

On the dictionary page, choose **Save offline** beside **Night mode** before
disconnecting. The application checks every downloaded file and runs a sample
lookup before reporting **Ready offline**. The button then becomes
**Check for updates**. The saved bundle includes the dictionary, fonts, help
and licenses. Queries do not add results to its storage.

## Install an app icon

Installation is optional. On iPhone or iPad, open the site in Safari and choose
**Share → Add to Home Screen**. Open it from the Home Screen and save the dictionary
there too. Other browsers may offer **Install app** or their own install command.
Installing an icon alone does not save the dictionary.

## Update a saved copy

**Check for updates** checks the current release and saved-file integrity.
An intact current copy reports **Up to date**. A newer release offers
**Download update**; a check does not download it automatically. Unchanged files
are reused after verification.

After the download is checked, choose **Reload with update** when convenient.
Your current input and results stay open until then. Failed or cancelled downloads
preserve the previous complete copy. Older open tabs keep their own resources;
close unused tabs to allow obsolete caches to be reclaimed.

## Interrupted downloads and missing files

Use **Cancel download** to stop a transfer. Retry after it finishes cancelling.
Update checks time out after 30 seconds; a download times out after three minutes
without progress. A slow transfer can continue while bytes are arriving.

If files are missing or damaged, reconnect and save again. Clearing this site's
data removes the offline dictionary and theme preference. Browsers may reclaim
storage when space is low; allowing persistent storage reduces that risk where
supported, but denying permission does not prevent saving.

Offline saving requires browser storage and a secure connection. Private browsing
or blocked storage can prevent it even when online lookup works. The source
archive download requires an internet connection.
